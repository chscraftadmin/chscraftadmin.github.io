SERVER ABOUT

Since 2024, this CHS Minecraft server has been running on-and-off with various worlds. Now, we've decided to open it up to even more people for more fun.

Being a server with some rules, and often facing downtime due to matinence, we've chosen to change URLs and establish a homepage to make information easier to obtain, and to make it easier for people without Discord to join the server.

This server prides itself in being welcoming and letting new people in, whether you're experience at Minecraft or not. If you've played thousands of times, or never before, please give the server a try :)

SERVER DETAILS
  • The server runs on 26.2 (The current version of MC!)
  • This is a JAVA server. This means that it only works on computers, no consoles or iPads.
  • The server runs with a whitelist, so you must be approved to join.
  • There are a few datapacks and plugins on the server, so expect staying up to date to be slow.
  • Contact the admin at chscraftadmin@gmail.com
